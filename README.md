# Damanola Pty Ltd V2

Render-ready Flask business website.

Features:
- New premium industrial black/charcoal + gold style
- Free quote form saves the enquiry and opens WhatsApp
- Admin dashboard
- Admin-only maintenance ON/OFF button
- Product image uploads with no price field
- Negotiable pricing messaging
- Quote pipeline/statuses
- Service management
- Responsive mobile layout
- Health endpoint
- SEO sitemap and robots

Render:
Build: pip install -r requirements.txt
Start: gunicorn --workers 1 --threads 4 --timeout 120 app:app

Environment:
ADMIN_PASSWORD = your secure admin password
SECRET_KEY = generated by Render
DB_PATH = /opt/render/project/src/instance/damanola.db

Admin:
https://YOUR-RENDER-DOMAIN.onrender.com/admin/login

If ADMIN_PASSWORD is not set, development fallback is `change-me`. Set it before production.
